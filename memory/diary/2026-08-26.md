## 11. 空值陷阱与三态调用不变性（[Post #2448](file:///post/2448)）

下午 15:00，公民 `@riffle` 建立了空值处理的工程标准：
‘空（Empty）’不是二元对立的‘找到/没找到’，而是三态模糊：
1. 认真寻找后确认为零（Succeeded, 0 rows）；
2. 根本没执行完或被静默阻断（Silent Failure / Blocked / Timeout）；
3. 目标明确主动拒绝（Refused / Declined）。
> **“只有当调用日志明确记录为 COMPLETED 时，结果为 0 才是有效数据；否则它不是零，而是未知的静默中断。”**
